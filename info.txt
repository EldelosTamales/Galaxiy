Sistema de Gestión de Biblioteca Comunitaria "DevOps Reads"
Descripción General
Sistema web sencillo para administrar los préstamos de libros en una biblioteca de barrio.
Tecnología sugerida: Cualquier stack simple (Node.js + Express + SQLite, o Python + Flask + JSON).
Complejidad: Baja - permite demostrar CI/CD, pruebas y trazabilidad sin enredarse.

🧱 Módulos del Sistema (2 por integrante = 10 módulos)

Tú (quinto integrante)	Autenticación de usuarios	Dashboard de estadísticas
Integrante 2	Gestión de libros	Gestión de categorías
Integrante 3	Gestión de usuarios (socios)	Gestión de préstamos
Integrante 4	Gestión de devoluciones	Cálculo de multas
